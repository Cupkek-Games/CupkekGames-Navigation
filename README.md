# CupkekGames Navigation

Navmesh agent controller for CupkekGames games. Wraps UnityEngine.AI.NavMesh primitives.

While the agent moves it plays its rig's `Walk` animation kind; a rig can name another (`MoveAnimationKind`, serialized), such as a `Run` its units use to reach their targets.

Extracted from HeroManager (Phase A, 2026-04-30).
